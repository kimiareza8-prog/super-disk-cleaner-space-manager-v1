# Super Disk Cleaner & Space Manager — Version 1

ابزار دسکتاپ ویندوز برای پاکسازی فایل‌های موقت و کش‌ها، نمایش وضعیت دیسک و RAM، پیدا کردن فایل‌های حجیم و دسترسی به ابزارهای نگهداری ویندوز.

A Windows desktop utility for cleaning temporary/cache files, monitoring disk and RAM usage, locating large files, and opening common Windows maintenance tools.

## Version
**v1.0 — نسخه ۱ / Version 1**

## Requirements
- Windows
- Python 3
- PyQt5
- psutil

## Run
```bash
pip install -r requirements.txt
python super_disk_cleaner_v1.py
```
